# Amazon Clone

## About the Project

This is a clone of the Amazon homepage that I built using only HTML5 and CSS3. I'm a BSCS student at UCP Gujranwala, and I made it to practice building a real-looking website from scratch.

It's a learning project and has no connection to Amazon.

## Features

- Header with the logo, delivery location, search bar with a category dropdown, language selector, sign-in and cart
- A second navigation bar with Prime Videos, Coupons, Today's Deals, Registry, Gift Cards and more
- A big "Back to School" banner
- Product cards for categories like Electronics, Furniture, Beauty, Watches, Gaming and Travel
- A "Sign in" section for new and returning customers
- A "Back to top" bar and a full footer with four link columns

## Built With

- HTML5
- CSS3

## Limitations

There is no JavaScript in this project, so buttons like the cart and search don't work yet. This is only the front-end design.

## How to Run

Download or clone the project and open `index.html` in your browser. You don't need to install anything.
